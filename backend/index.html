ChristopherStore API

Lightweight backend for the ChristopherStore Android app.

Available Endpoints

GET /apps

Returns a list of all available apps.

GET /apps/:id

Returns detailed information about a specific app.

GET /apps/:id/:version/download

Redirects to the download URL for a specific version of an app.

Implementation

This API is implemented as a static site on GitHub Pages with client-side routing. For production use, deploy the Cloudflare Workers version for better performance and server-side routing.
